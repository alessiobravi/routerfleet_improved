Backup clean-up

A duplicate is a stored backup whose configuration is the same as the stored backup before it. Cleaning turns it into an unchanged backup - it stays in the history and opens the configuration it repeats - and frees its copy, as keep only changes does for new backups. Backups made with Backup now are never touched.
