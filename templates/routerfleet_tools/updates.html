On the host, in the folder of the compose file:

The database is PostgreSQL {{ database_major }}
With your compose file as it is, the command above is all. Taking the current compose file moves the database to PostgreSQL 18 - the database then waits for this script, run on the host in the folder of the compose file:
mkdir -p scripts
wget -O scripts/migrate-database.sh https://raw.githubusercontent.com/alessiobravi/routerfleet_improved/main/scripts/migrate-database.sh
chmod +x scripts/migrate-database.sh
./scripts/migrate-database.sh
If you changed the ports in your compose file (another web server on 80 or 443), set HTTP_PORT and HTTPS_PORT in .env before - the current compose file reads them from there. Every step, and the way back: docs/upgrading.md, "Moving to PostgreSQL 18".
