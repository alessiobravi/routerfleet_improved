Gives the space of deleted data back to the disk. Each table is locked while it is rewritten: pages wait.
What happens exactly

Every table is copied into a new, compact file and the old one removed. While a table is copied, pages and backups that need it wait - seconds on a small database, minutes on a large one - and the disk needs free space as large as the biggest table.

Afterwards the database takes less space on disk and works exactly as before. Worth it after deleting a lot - a large backup clean-up, many devices removed - when the disk runs short. Without it, the space stays with the database and is reused for new data, and nothing waits.
